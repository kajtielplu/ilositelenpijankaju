# ilo sitelen pi jan kaju

## toki pona

ni li ilo pi sitelen pona.

1. o pana e ni tawa ilo sona sina.
2. o pali e `install.sh`. ante la, o pali e ni anpa:

```bash
sudo ibus-table-createdb -n /usr/share/ibus-table/tables/toki-pona.db -s toki-pona.txt
sudo ibus-daemon -drx
```

## english

IME keyboard for entering UCSUR sitelen pona characters. see more [here](https://kaiju.blue/sitelen_pona).

requires ibus. download then run the `install.sh`, or alternatively run the commands shown above.
